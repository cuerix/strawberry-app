# 딸기(설향 고설재배) 기술지도 진단 도우미 ver1.0

- 앱 주소: https://cuerix.github.io/strawberry-app/
- 사용설명서: https://cuerix.github.io/strawberry-app/guide.html
- 기준: 딸기 설향 고설재배 기술지도 매뉴얼 개선 7차
- 아이폰: Safari로 열기 → 공유 → 홈 화면에 추가 / 안드로이드: Chrome·삼성인터넷 → 메뉴 → 앱 설치(홈 화면에 추가)
- 기록은 각 휴대전화 안에만 저장됩니다(서버 전송 없음). 처음 한 번 연 뒤에는 인터넷 없이도 동작합니다.
- 새 버전 배포: index.html만 교체(주소는 바꾸지 마세요).
